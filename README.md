# 🛒 Atliq Hardware - SQL Business Analysis

An end-to-end MySQL business data analysis project exploring sales performance, customer behavior, product trends, and profitability for Atliq Hardware (a consumer electronics company).

---

## 📊 Project Overview
This project solves **10 ad-hoc business request queries** for top management to help make data-driven decisions regarding regional markets, product growth, manufacturing costs, pre-invoice discounts, gross sales, and sales channels.

## 🛠️ Tech Stack & Skills Demonstrated
* **Database:** MySQL
* **Tools:** MySQL Workbench, Git & GitHub
* **SQL Concepts Used:** 
  * Common Table Expressions (`WITH` clauses)
  * Window Functions (`RANK() OVER (PARTITION BY ...)`)
  * Subqueries & Aggregations (`GROUP BY`, `HAVING`, `SUM`, `AVG`, `COUNT(DISTINCT)`)
  * Multi-table Joins (`INNER JOIN`)
  * Conditional Logic (`CASE WHEN`)

---

## 💡 Key Business Insights
1. **Top Markets:** Customer "Atliq Exclusive" operates successfully in the APAC region (Market: APAC).
2. **Product Expansion:** Unique product count grew significantly from 2020 to 2021.
3. **Sales Channel Dominance:** The **Retailer** channel generated the highest gross sales in fiscal year 2021, accounting for the vast majority of total revenue.
4. **Discounts & Regions:** Identified top 5 customers receiving high pre-invoice discounts in the Indian market for FY2021.
